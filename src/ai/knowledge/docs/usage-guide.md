# Vision-Craft 使用指南

Vision-Craft 是一个可视化大屏搭建平台，支持拖拽式组件编排和 AI 智能生成。

## 平台概览

### 核心功能

- **拖拽式编辑器**: 从组件面板拖拽组件到画布，自由布局
- **AI 大屏生成**: 用自然语言描述需求，AI 自动生成完整大屏
- **实时预览**: 编辑时所见即所得，支持独立预览模式
- **项目管理**: 创建、保存、管理多个大屏项目

### 页面导航

- `/` — 首页
- `/auth` — 登录/注册
- `/projects` — 项目列表（需登录）
- `/editor/:id` — 编辑器（需登录）
- `/preview/:id` — 预览页（需登录）

## 编辑器使用

### 界面布局

编辑器由以下区域组成：

1. **顶部工具栏**: 保存、预览按钮
2. **左侧组件面板**: 基础组件和图表组件的分类列表
3. **中间画布**: 大屏编辑区域，支持缩放和标尺
4. **右侧属性面板**: 选中组件的属性编辑 + AI 对话面板

### 添加组件

两种方式：

1. **拖拽添加**: 从左侧面板拖拽组件到画布上
2. **AI 生成**: 在右侧 AI 对话面板输入需求，AI 自动生成组件

### 编辑组件

选中画布上的组件后：

- 拖动改变位置
- 拖动边缘调整大小
- 在右侧属性面板修改具体属性
- 支持 AI 精准修改：点击组件上的 AI 编辑输入框，输入修改指令

### AI 大屏生成

#### 创建模式

在 AI 对话面板中输入自然语言描述，例如：

- "智慧园区运营大屏，显示园区概览、能耗、客流、工单"
- "电商实时数据大屏，包含 GMV、转化、订单分布、品类占比"
- "生产制造监控，展示产线 OEE、停线告警、设备状态、良率趋势"

AI 会通过 SSE 流式返回组件，逐个添加到画布上。

#### 多轮对话

AI 支持多轮对话，可在现有画布基础上追加或修改：

- "再加一个折线图显示月度趋势"
- "把柱状图改成堆叠样式"
- "修改页面背景色为深蓝色"

#### 组件精准修改

选中组件后，可以通过 AI 精准修改单个组件的属性：

- "把标题改成红色"
- "数据改为最近 6 个月的销售额"
- "调整字号为 24px"

### 保存与预览

- 点击"保存"按钮保存当前编辑状态
- 点击"预览"按钮在新标签页中查看大屏效果
- 注意：AI 生成的内容不会自动保存，请手动保存

## 数据源配置

### 静态数据源

直接在组件的 dataSource.data 中提供 JSON 数据数组。适用于演示和固定数据场景。

### API 数据源

配置 dataSource.sourceType 为 "api"，设置 apiUrl 指向数据接口。

支持 refreshInterval 实现自动定时刷新，适用于实时数据监控场景。

### 字段映射

通过 dataSource.fieldMapping 将数据字段映射到图表维度：

- 映射 key 为语义名称（如 x, y, name, value, series, category, size）
- 映射 value 为数据中的实际字段名

详细的字段映射规范请参考《图表配置与数据源指南》。

## 常见问题

### 如何配置图表数据？

1. 选中图表组件
2. 在右侧属性面板找到"数据源"区域
3. 选择数据类型：静态数据或 API 接口
4. 配置数据内容和字段映射

### 如何修改页面背景？

可以通过 AI 对话："修改页面背景色为 #0a1628" 或 "搜索一张科技感背景图"。

### 组件超出画布怎么办？

画布默认尺寸为 1920×1080，网格大小 15px。确保组件的 style.top + style.height <= 1080，style.left + style.width <= 1920。

### 如何使用容器组件？

Container 组件支持 absolute 和 flex 两种布局模式。absolute 模式下子组件自由定位，flex 模式下子组件自动排列。
